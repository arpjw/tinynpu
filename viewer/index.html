The model. Load → compute → store, with no overlap. Both operands reload for each tile. Padding is generated locally; only useful operands and INT32 outputs transfer. An ideal local buffer feeds the array.

The boundary. Bias, ReLU, rescaling, and argmax run on the host and are excluded from timing. These are simulated and modeled cycles, not physical latency, clock frequency, power, or silicon area.
